# README

# Практическая работа №5: Разработка приложения с использованием текстовых компонентов в WPF и C#

## Цель работы

Закрепить теоретические знания по теме «Текстовые компоненты WPF» и получить практические навыки разработки оконных приложений на языке C# с использованием элементов `TextBlock`, `TextBox`, `Label` и `PasswordBox`.

## Описание проекта

WPF-приложение **«Личный дневник заметок»**, демонстрирующее работу с текстовыми компонентами для ввода, отображения и редактирования текстовой информации. Приложение позволяет создавать заметки, просматривать их, очищать поле ввода и удалять все заметки.

---

## Архитектура и структура проекта

### 1. `MainWindow.xaml` — главное окно (интерфейс)

Разметка построена на `Grid` с тремя колонками и четырьмя строками:

| Область | Элемент | Назначение |
|---------|---------|------------|
| Шапка (`Row 0`) | `TextBlock_Header` | Вывод ФИО, группы, названия ПР и описания |
| Подпись (`Row 1, Col 0`) | `Label_Note` | Подпись поля ввода «Ваша заметка:» |
| Ввод (`Row 2, Col 0`) | `TextBox_Note` | Многострочное поле с прокруткой (`AcceptsReturn`, `TextWrapping`, `VerticalScrollBarVisibility`) |
| Панель кнопок (`Col 1`) | `StackPanel` с 5 `Button` | Управляющие кнопки |
| Список (`Row 1-2, Col 2`) | `Label` + `ListBox_Notes` | Отображение сохранённых заметок |
| Счётчик (`Row 3`) | `TextBlock_Status` | Отображение количества заметок |

### 2. `MainWindow.xaml.cs` — логика окна

- Поле `_noteManager` — экземпляр `NoteManager`.
- Конструктор вызывает `InitializeComponent()` и `DemonstrateTextComponents()`.
- `RefreshListBox()` — обновляет `ListBox_Notes` из менеджера.
- `UpdateStatus()` — обновляет `TextBlock_Status` (`Заметок: N`).
- Обработчики пяти кнопок (`Button_*_Click`).

### 3. `NoteManager` — бизнес-логика (вложенный класс)

| Член | Назначение |
|------|------------|
| `List<string> _notes` | Хранилище заметок |
| `int Count` | Количество заметок |
| `void AddNote(string text)` | Добавляет заметку (с проверкой на пустоту и `Trim`) |
| `List<string> GetAllNotes()` | Возвращает копию списка заметок |
| `void ClearAllNotes()` | Очищает список |

## Функциональные возможности

### Главное окно (точка входа)

При запуске приложения:
- В **заголовке окна** выводится ФИО, группа и название ПР.
- В **шапке** (`TextBlock_Header`) — ФИО, группа, название ПР и краткое описание.
- В **статусной строке** — текущее количество заметок.

### Интерактивный интерфейс (5+ элементов управления)

Использованы элементы:
- **`TextBlock`** — шапка и счётчик.
- **`Label`** — подписи поля ввода и списка.
- **`TextBox`** — многострочный ввод заметки.
- **`ListBox`** — список сохранённых заметок.
- **`Button`** — 5 кнопок управления.

### Обработка кнопок интерфейса

| № | Кнопка | Действие |
|---|--------|----------|
| **1** | Добавить заметку | Считывает текст из `TextBox_Note`, проверяет на пустоту, добавляет в `NoteManager`, очищает поле, обновляет `ListBox` и статус, показывает `MessageBox` с количеством |
| **2** | Показать все заметки | Обновляет `ListBox` и статус, показывает `MessageBox` с количеством |
| **3** | Очистить поле ввода | Очищает `TextBox_Note`, показывает `MessageBox` с количеством заметок |
| **4** | Удалить все заметки | Вызывает `ClearAllNotes()`, очищает `ListBox`, обновляет статус, показывает `MessageBox` |
| **5** | Выход | Закрывает окно (`Close()`) |

### Подтверждение действий

После каждой операции выводится `MessageBox` с актуальным количеством заметок:

```
Заметка добавлена. Всего заметок: 3
```

```
Все заметки удалены. Всего заметок: 0
```

```
Поле ввода очищено. Всего заметок: 5
```

### Демонстрация работы текстовых компонентов

В конструкторе вызывается `DemonstrateTextComponents()`:
- Добавляет 3 предустановленные заметки через `AddNote`.
- Обновляет `ListBox` (`RefreshListBox()`).
- Добавляет 3 демонстрационные заметки разной длины (короткая, с числом и датой, длинная многострочная).
- Повторно обновляет `ListBox` и статус.

Это показывает, что `TextBox` и `ListBox` корректно работают с текстом разной длины и содержимого.

## Дополнительные особенности реализации

- **Проверка на пустоту:** `string.IsNullOrWhiteSpace` перед добавлением заметки, предупреждение через `MessageBox`.
- **Обрезка пробелов:** `text.Trim()` при добавлении заметки.
- **Защита списка:** `GetAllNotes()` возвращает копию списка (`new List<string>(_notes)`), а не ссылку на внутренний список.
- **Многострочный ввод:** `TextBox` с `AcceptsReturn="True"`, `TextWrapping="Wrap"`, `VerticalScrollBarVisibility="Auto"`.
- **Адаптивная вёрстка:** использование `Grid` с `ColumnDefinition` (`2*`, `Auto`, `3*`) и `RowDefinition` (`Auto`, `Auto`, `*`, `Auto`) — интерфейс растягивается вместе с окном.
- **Центрирование окна:** `WindowStartupLocation="CenterScreen"`.
- **Информативные сообщения:** `MessageBox` с заголовками «Готово», «Внимание», «Список заметок» и соответствующими иконками (`Information`, `Warning`).
